# 🏢 Enterprise Customer Churn Prediction & Retention Analytics Platform

An end-to-end Machine Learning web platform that predicts customer churn risk, identifies the root causes using Explainable AI (SHAP), and prescribes targeted retention strategies.

🔗 **Live Demo:** [Click here to try the Web App](https://customer-churn-platform-cknkszwnljqxpyl8sdh4bj.streamlit.app)

---

## 📌 Project Overview
Customer acquisition costs 5x more than customer retention. This platform enables customer success and retention teams to:
1. **Predict Risk:** Calculate the exact churn probability for any customer.
2. **Explainable AI (SHAP):** Reveal the exact drivers behind why a customer wants to cancel.
3. **Prescriptive Retention:** Automatically generate customized retention offers and pre-drafted outreach emails.
4. **Batch Processing:** Upload lists of 100+ customers at once and export prioritized action plans.

---

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **Machine Learning:** XGBoost Classifier, Scikit-learn
- **Explainable AI:** SHAP (Shapley Additive exPlanations)
- **Frontend & Visualization:** Streamlit, Plotly Interactive Charts
- **Deployment:** Streamlit Community Cloud

---

## 📊 Inputs & Features
- **Profile:** Age, Tenure with Company
- **Subscription:** Contract Type (Month-to-month, 1-yr, 2-yr), Internet Service
- **Usage:** Monthly Data Usage (GB)
- **Billing:** Monthly Charges ($), Late Payments Count
- **Support:** Support Interactions / Complaints Count
